# Cartas a Inversores

Las cartas de los gestores value hispanos que lee Ezra Crangle, enlazadas a la web de cada gestora.
Sitio: https://cartas.ezrasnotes.com · Versión en inglés: https://letters.ezrasnotes.com

Mismo funcionamiento que el sitio en inglés: `managers.yaml` dice dónde buscar, la revisión semanal
(GitHub Actions) añade las cartas nuevas a `data/letters.json` y `scripts/build.py` genera `docs/`.
Solo se guardan enlaces; ningún PDF se aloja aquí.
